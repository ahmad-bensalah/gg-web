# gg-web: Orb Catcher

A tiny browser game. Catch the glowing orbs with your paddle and dodge the red spikes. Missing an orb or hitting a spike costs a life. The game speeds up over time, and your best score is saved in the browser.

## Play

Open `index.html` in a browser, or enable GitHub Pages for this repo.

Controls: ← → or A / D, or drag on touch screens. Space or the Start button starts a round.
